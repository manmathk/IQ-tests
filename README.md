# IQ Live — 24/7 Vertical Brain Challenge

A portrait-first browser game designed for YouTube Live capture. The game runs autonomously: each round presents a timed IQ puzzle, reveals the answer and explanation, then advances to the next challenge. After 20 rounds it shows a score card and can restart.

## Included game types

- Number Pattern
- Odd One Out
- Sequence
- Memory
- Word Logic
- Math Trap

## Live-stream design

- 9:16 portrait stage for vertical YouTube streams
- Large timer plus progress bar
- Automatic answer reveal after the timer expires
- Automatic round progression
- Score counter and 20-round session result
- Responsive layout that remains readable on mobile and desktop
- No server, database, or build step required

## Run

Open `index.html` directly in a browser, or host the repository with GitHub Pages / any static host.

For a 24/7 YouTube Live stream, capture the browser window in OBS and use a 1080x1920 vertical canvas. Keep the page active so the automatic round timer can continue.
