# IQ Live Puzzle Style Update

Target visual style: 9:16 vertical YouTube Live puzzle cards inspired by the latest generated quiz images.

Design requirements:
- Large puzzle equation is the primary visual element.
- Large `COMMENT YOUR ANSWER!` call to action.
- Four large A/B/C/D answer cards.
- No large countdown/timer on the puzzle card.
- Include accuracy/points messaging and leaderboard language.
- Use emoji/illustration equations such as animals, fruit, objects and symbols.
- Keep every generated puzzle mathematically verified before display.
- Avoid invalid answer sets: the exact correct answer must always appear in exactly one option.
- Prefer a self-contained puzzle card suitable for capturing as a vertical 1080x1920 stream scene.
